Besides <DynamicLink href="/[lang]/docs/chat-tools">built-in tools</DynamicLink>, Everywhere can connect to tools provided by external **MCP (Model Context Protocol)** servers. Two transports are supported:

- **Stdio** — launches a local process and communicates over standard input/output.
- **HTTP** — connects to a remote server over HTTP (**Streamable HTTP** by default, or **Auto Detect** / legacy **SSE**).

<Callout type="warning" title="SSE">
HTTP+SSE support has been deprecated in favor of Streamable HTTP. Please use Streamable HTTP for new servers.
</Callout>

On the **Tools** page, open the **MCP Server** tab. You can **Add** a server manually, or **Import from JSON**.

## Adding a Server

Click **Add** to open the configuration dialog. Fields marked with `*` are required.

<HorizontalImg
  src="/chat-tools/mcp-en.webp"
  alt="Add MCP Server configured for DeepWiki with its URL and Streamable HTTP transport."
  width="min(100%, 640px)"
/>

When you click **OK**, Everywhere verifies the server connection inline and shows live startup progress. You can press `Escape` or click **Cancel** to abort verification; if initial verification fails, the server is still saved with a warning so you can edit or start it later.

## Importing from JSON

Click the **Import from JSON** icon next to **Add** to paste a JSON configuration or click **Open** to load a `.json` file. Comments (`//`) and trailing commas are supported.

Supported JSON formats:
* `{ "mcpServers": { "name": { ... } } }`
* `{ "server1": { ... }, "server2": { ... } }`
* `[ { "name": "...", "command": "..." }, ... ]`
* A single server object `{ "command": "...", ... }` or `{ "type": "sse", "url": "..." }`

Recognized properties include `name`, `command`, `args` / `arguments`, `env` / `environmentVariables`, `url`, `headers`, and `type` (`"stdio"`, `"http"` / `"streamable-http"`, `"sse"`). *(Note: `Working Directory` is configured in the Edit dialog.)*

## Managing Servers, Runtimes & Approval

* **Status & Lifecycle**: Each MCP entry shows a status indicator (**Gray** = Not Running, **Green** = Running) and **Run**, **Stop**, **Edit**, and **Remove** actions. Enabled MCP servers also start automatically when a chat begins; if one server fails to start, the conversation continues with the remaining available tools and shows a warning.
* **Tools & Logs Tabs**: Discovered tools are cached locally so they remain visible and configurable before starting the server. The **Logs** tab shows recent server output and errors, with **Show Timestamp** and **Copy all logs to clipboard** controls.
* **Automatic Runtime Dependency Resolution**: If a Stdio server uses `uv` / `uvx`, `node` / `npm` / `npx`, `bun` / `bunx`, or `docker` and the runtime is missing on your system, Everywhere shows a warning with a **Resolve** button to automatically download and install `uv`, `Node.js` (LTS), or `Bun` (or open the Docker setup guide).
* **Approval Controls**: MCP tools require confirmation by default. You can toggle **Bypass approval for all tools** at the server level, toggle **Bypass Approval** per tool, or choose **Always allow all tools from “...”** directly from an approval prompt.
* **Automatic Reconnection**: If a remote HTTP session expires during a conversation, Everywhere automatically reconnects when possible.
