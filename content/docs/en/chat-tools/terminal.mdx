## Settings

### Terminal Path

Located under **Tools > Terminal > Settings**.

Custom path for the terminal executable, supporting only PowerShell, zsh, and bash.

**Leave blank**: Automatically detects the system default terminal (on Windows, PowerShell 7+ is preferred when installed, otherwise Windows PowerShell; macOS uses zsh; Linux uses bash).

## Approval Behavior

For security, **Execute In Terminal** cannot be set to permanently bypass approval in **Tools > Terminal**. Depending on the active **Tool Approval Mode** in the chat window:
* **Request approval**: Prompts before each command, with **Allow once** and **Allow in session** choices.
* **Approve for me**: Reviewed automatically by the configured approval assistant.
* **Full access**: Executes without prompting.
