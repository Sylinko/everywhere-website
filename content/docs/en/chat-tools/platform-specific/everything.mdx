Available on **Windows** only. Complements the built-in <DynamicLink href="/[lang]/docs/chat-tools/file-system">File System</DynamicLink> tools with much faster local file discovery powered by the **Everything** search engine. Everywhere starts the Everything service automatically when searching and stops it when idle.
