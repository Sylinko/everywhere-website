Available on **Linux** only (**disabled by default**). Complements the built-in <DynamicLink href="/[lang]/docs/chat-tools/file-system">File System</DynamicLink> tools with fast local file search powered by `fd` / `fdfind`.

<Callout type="info" title="Prerequisite">
Requires <code>fd</code> or <code>fdfind</code> installed on your system (e.g. <code>sudo apt install fd-find</code> on Debian/Ubuntu, <code>sudo dnf install fd-find</code> on Fedora, or <code>sudo pacman -S fd</code> on Arch Linux).
</Callout>
