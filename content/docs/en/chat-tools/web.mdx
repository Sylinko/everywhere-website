## Settings

All Web settings are located under **Tools > Web > Settings**.

### Web Search Engine

Select the search provider used by **Web Search**:

* **Everywhere Cloud**: Built-in cloud search powered by your Everywhere Cloud account, with configurable **Search Depth**, **Search Topic** (`General` / `News`), and **Time Range**.
* **AnySearch** *(Default)*: Supports an optional API Key and custom API Url.
* **Bocha**, **Brave**, **Jina**, **Serply**, **Tavily**, **UniFuncs**: Require an API Key (and optional custom API Url).
* **Google**: Requires an API Key and a programmable **Search Engine ID**.
* **SearXNG**: Self-hosted meta-search endpoint (**API Url** only, no API Key required).

### Show Browser in Foreground

When enabled, the browser window is displayed while **Extract Web Content** runs, which is generally not recommended.

**Default**: Disabled

### Open Browser

Opens an instance of the browser used for extracting webpages so you can sign in to frequently used sites in advance and reduce the chances of being flagged as a bot during extraction. If no compatible browser is available locally, the first launch may automatically download one, which may take some time depending on network conditions.
