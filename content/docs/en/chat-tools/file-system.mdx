Listed in the app under **Tools > Built-in > File Operations**.

<Callout type="error" title="Security">
File operations performed by the assistant are **irreversible** (deletions permanently remove files rather than moving them to Trash). Please ensure you have backed up important data before allowing modifications.
</Callout>

<Callout type="tip">
On Windows, pair these tools with <DynamicLink href="/[lang]/docs/chat-tools/platform-specific/everything">Everything</DynamicLink> (or <DynamicLink href="/[lang]/docs/chat-tools/platform-specific/fd-find">fd-find</DynamicLink> on Linux) for ultra-fast local file discovery. For <code>.docx</code>, <code>.xlsx</code>, and <code>.pptx</code> documents, use <DynamicLink href="/[lang]/docs/chat-tools/office">Office Suite</DynamicLink>.
</Callout>

## Settings & Approved Paths

### Approved paths

Located under **Tools > File Operations > Settings**.

You can configure a list of folder path rules (using `/` as separator and `**` for nested folders, for example `C:/Source/Everywhere/**`). File operations within matching folders skip repeated folder-approval prompts (except high-impact actions such as deleting non-empty folders).

<Callout type="info" title="Chat Workspace & Quick Approval">
* **Chat Workspace**: Routine file operations inside the conversation's own working folder are approved automatically.
* **Quick Approval Options**: When prompted for a file operation outside approved paths, you can choose **Always allow the listed paths**, **Always allow** the parent folder, or **Always allow a selected folder…** to save the rule right away.
</Callout>
