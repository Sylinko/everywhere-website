## Notes

### Automate Actions

<Callout type="warning">
**Query Visual Context**, **Reading visual text**, and **Automate Actions** are marked **Experimental** and may change or behave unpredictably depending on the target app and model. Use automated actions with caution.
</Callout>

The decision to execute actions on UI elements is determined by the model itself. In some cases, the model may refuse to perform UI interactions or produce imprecise results.

### Platform & Software Compatibility

Screen Awareness is supported across **Windows**, **macOS** (requires granting Accessibility and Screen Recording permissions in System Settings), and **Linux** (supported across major desktop environments and compositors).

Because visual trees rely on OS accessibility features, **content cannot be retrieved from software that does not expose accessibility information (such as WeChat)**. Fullscreen games and DRM-protected windows are also unsupported.

### Real-time Capability

Visual context acquisition works like a snapshot rather than a live video stream, so real-time tasks such as live subtitle translation are not possible.
