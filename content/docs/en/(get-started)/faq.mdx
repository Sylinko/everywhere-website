## Payments & Accounts

### I subscribed to ChatGPT Plus/Team/Pro or a similar service—why am I told my balance is insufficient?

Consumer web subscriptions such as ChatGPT Plus/Team/Pro or Google AI Pro are billed separately from developer APIs.

**You must top up API credits separately when using Bring Your Own Key (BYOK), or sign in with your Sylinko Passport to use Everywhere Cloud.**

## Model Providers

### How do I configure gateway or local providers (such as Ollama, LM Studio, Qwen, or Doubao)?

First check **Preset Mode** under **Assistants**, which already includes 14 built-in providers (including OpenRouter, SiliconFlow, Mistral, ZhipuAI / Z.ai, OpenAI, Anthropic, Google, DeepSeek, MoonshotAI, and MiniMax).

For **Ollama**, **LM Studio**, or other compatible endpoints not listed in Preset Mode, switch your assistant to **Advanced Mode** (*Custom Protocol*), select the matching **API Schema**, enter the endpoint URL and Model ID, and verify the normalized URL in the live preview below the URL field.

See <DynamicLink href="/[lang]/docs/models#local-and-custom-endpoints">Models & Providers — Local & Custom Endpoints</DynamicLink> for details.

### Why isn't my unofficially supported model provider working?

**Everywhere** ships built-in support for **Everywhere Cloud** and 14 **Preset Mode** providers, where we maintain compatibility and stability.

For other OpenAI/Anthropic/Google/Mistral/Ollama-compatible providers, configure them manually via **Advanced Mode** (see <DynamicLink href="/[lang]/docs/models#local-and-custom-endpoints">Models & Providers</DynamicLink>). Because there are many third-party and self-hosted API implementations, we cannot test every unofficially supported endpoint—if you encounter issues, check the live URL preview and contact your provider, or switch to a preset or cloud model.

### The AI gives no response

If there is no response after asking a question (even though status indicators appear), check your **URL** and **API Schema** in Advanced Mode.

A common mistake is omitting `/v1` on OpenAI-compatible URLs (e.g., entering `https://api.example.com` instead of `https://api.example.com/v1`).

<Callout type="tip" title="Check the Live URL Preview">
1. If your provider is available in **Preset Mode**, keep the preset configuration rather than manually overriding URLs.
2. In **Advanced Mode**, check the live URL preview below the **URL** field—Everywhere automatically normalizes standard paths, and appending `#` at the end tells Everywhere to use your URL verbatim without adding suffixes.

### Why can't I read images?

**Not all models support image input.**

If you attach or capture an image with a text-only model (or an Advanced Mode configuration without **Image** selected under **Input Modalities**), Everywhere displays: `"The current assistant does not support image input."`

Switch to a vision-capable model (and ensure **Image** is selected under **Input Modalities** in Advanced Mode). If the assistant reads image files on disk using **View images**, make sure **Essential > View images** is enabled and check **Settings > System Assistant > Image Understanding Subagent**.

### Why can't I use web search?

By default, model APIs do not include web search the way web apps like ChatGPT or DeepSeek do. Everywhere provides web search as a built-in tool:

- **Everywhere Cloud Search (Recommended)**: Use your account credits or the monthly search quota included in your [subscription plan](/en/pricing) with zero extra setup.
- **Custom Search Engines**: Configure API keys for external providers (such as Google, Brave, Tavily, Bocha, etc.) under **Tools > Web** in the main window.

See <DynamicLink href="/[lang]/docs/chat-tools/web">Tools — Web</DynamicLink> for complete configuration details.

## Software Usage & Permissions

### Why can't I bring up the floating chat window?

1. **Hotkey Conflict or Disabled Hotkey**: Your global hotkey may conflict with another app (e.g., screenshot tools or input methods), or may have been disabled during setup or from the tray menu.
   - **Solution**: Check **Settings > Shortcuts** (or the tray menu's **Chat Window Shortcut** toggle) and assign a non-conflicting shortcut.
2. **Administrator Windows (Windows)**: When an elevated application (e.g., Task Manager or an installer) is focused, Windows UAC isolation prevents non-elevated apps from interacting with it.
   - **Solution**: In **Settings > Common**, turn on **Install as a service** so Everywhere can recognize and interact with elevated apps cleanly.
3. **macOS Accessibility / Screen Recording Permissions**: On macOS, grant **Accessibility** and **Screen Recording** permissions in **System Settings > Privacy & Security** so Everywhere can register global shortcuts, capture selections, and read screen context.
4. **Linux Wayland Portal / Compositor Permissions**: On KDE Plasma 6 / GNOME, approve the system GlobalShortcuts permission prompt; on Niri, bind the launch command in your compositor configuration. See <DynamicLink href="/[lang]/docs/linux">Linux compatibility</DynamicLink>.

### How does tool approval work (e.g., Terminal / File Operations)?

You can switch between three **Tool approval** modes directly in the chat window toolbar:

- **Request approval** *(Default)*: Prompts you before running sensitive operations (such as terminal commands, modifying files outside your workspace, or calling MCP tools). You can select **Allow once**, **Allow in session**, **Always allow**, or deny.
- **Approve for me**: Lets a designated review assistant (configured in **Settings > System Assistant > Tool approval**) evaluate the risk based on your task. High-risk operations are still denied automatically.
- **Full access**: Allows all enabled tools to run without confirmation prompts (shows a warning banner; use only when you accept the risk).

### How do I send a message while the AI is still replying?

While a response is generating, you can set your default behavior under **Settings > Chat Window > Default Send Behavior When Busy**: **Queue** (waits until the current reply finishes) or **Send Immediately** (interrupts and steers the reply right away, shown as **Steer now**). While typing, you can also press `Ctrl/⌘ + Enter` (or `Ctrl/⌘ + Shift + Enter` in `Ctrl+Enter` mode) to send with the opposite mode, or edit, reorder, and remove queued messages above the input box.
