Every message sent to an AI model consumes tokens, which directly affects API bills or Everywhere Cloud credits. Tuning a few settings in Everywhere can cut token usage significantly without hurting answer quality.

## Screen Awareness & Visual Context

Screen awareness helps Everywhere understand what is on your screen, but large UI trees can add a lot of input tokens.

In the chat window, click the **Select assistant** menu in the bottom toolbar and open **Advanced Settings** (these same controls also live under **Assistants > Advanced Settings** in the main window):

### Screen Awareness Budget

- **What it does**: Caps how much screen content is read per perception (**Minimal (~1024)**, **Balanced (~4096, Recommended)**, **Detailed (~10240)**, **Ultimate (~40960)**, or **Unlimited (⚠️)**).
- **Tip**: **Balanced (~4096, Recommended)** works well for everyday tasks; switch to **Minimal (~1024)** when you only need a quick check on simple UI elements.

<Callout type="tip">
This cap is an estimate; actual tokens sent depend on how complex the active window is.
</Callout>

### Maximum Context Rounds

- **What it does**: Limits how many recent user-assistant turns stay in the conversation history sent to the model (`-1` for unlimited, `0` for current input only, up to `30`).
- **Tip**: Keep `-1` for multi-step work (and let context compression handle long threads), or set a smaller number for one-off tasks like translation and quick Q&A.

### Automatically Add Element

In **Settings > Chat Window**, **Automatically Add Element** is **off by default**. Leaving it off ensures Everywhere does not attach screen context automatically whenever you open the chat window—attach a screen element or screenshot from the paperclip menu only when the assistant actually needs to see your screen.

## Context Compression & Usage Monitoring

Long conversations grow steadily with each turn. Everywhere helps keep them compact:

- **Context usage**: Click or hover over the circular usage indicator next to the send button to open the **Context usage** panel and check used tokens, percentage, and **Cached input** tokens.
- **Automatic Compression**: Set **Context Compression Threshold** (`5%–95%`, default `80%`) under **Assistants > Advanced Settings**. Once usage reaches this percentage, Everywhere summarizes earlier messages automatically.
- **Manual Compaction & New Chats**: Open the **Context usage** panel anytime and click **Compact context** to shrink a long thread manually, or press `Ctrl + N` to start a fresh chat when switching topics.

## Prompt Caching & System Prompts

Everywhere keeps leading system instructions and tool definitions stable within an active conversation so providers can reuse cached prefixes:

- **Use `{Date}`**: Keeping dates at day granularity (`{Date}`) prevents your system prompt from changing every turn and breaking cache hits.
- **Keep Custom Prompts Concise**: Review your prompts on the **Prompts** page and trim redundant instructions.
- **Anthropic Prompt Cache**: When using the `Anthropic` schema, keep **Prompt Cache** enabled (set to **Ephemeral** by default) under **Assistants > Advanced Settings > Anthropic Messages Settings**.
- **Parallel Tool Calls**: The built-in `{DefaultSystemPrompt}` already encourages models to run independent tool calls in parallel, cutting down extra round-trip turns.

## Per-Assistant Tools & `Ctrl/⌘ + T`

Every enabled tool adds its name, description, and parameters to the model context:

- **Turn Off Tools for Plain Chat**: For writing, translation, or brainstorming, press `Ctrl/⌘ + T` in the chat window (or turn off **Tools** in the assistant menu) to skip tool definitions altogether.
- **Customize Tools Per Assistant**: Under **Assistants > Tools**, turn off **Follow global tool settings** to build focused, lightweight assistants that only enable the tools a workflow actually needs (also adjustable directly from the **Tools** panel inside the chat window's assistant menu).
