You can create, reorder, duplicate, and configure assistants on the **Assistants** page in the main window sidebar.

<Callout type="info" title="Check Connectivity & Managing Assistants">
- Click **Check Connectivity** in the top-right corner of the **Assistants** page to verify your model configuration and network connection (this sends a tiny test request and may consume a minimal amount of credits or API usage).
- Use the top-right toolbar buttons to **Duplicate** or **Delete** an assistant, and **drag** assistants in the left list to change their order (which also updates their `Ctrl/⌘ + 1–9, 0` shortcut order).
</Callout>

## Basic Info

- **Icon**: Click the assistant avatar to choose a built-in icon or Emoji and customize its icon and background colors.
- **Name**: Set a clear name to distinguish assistants when switching in chat.
- **Description**: Add a short note describing what the assistant is for.

## Configuration Tabs

Each assistant provides four tabs below its header for model setup, system prompt selection, tool overrides, and advanced options.

### 1. Model Configuration

Choose one of three modes at the top of the model tab (see <DynamicLink href="/[lang]/docs/models">Models & Providers</DynamicLink> for details):

- **Native Mode** (*Everywhere Cloud*): Zero-configuration official service—sign in with your Sylinko Passport and pick any supported model.
- **Preset Mode** (*Built-in Providers*): Pick from **14 built-in providers** (including OpenAI, Anthropic, Google, Mistral, DeepSeek, MoonshotAI, MiniMax, OpenRouter, SiliconFlow, and ZhipuAI / Z.ai), select or add an API key, and choose a model from the list.
- **Advanced Mode** (*Custom Protocol*): Connect any custom or local endpoint (such as **Ollama**, **LM Studio**, or private gateways):
  - **URL**: Enter the base URL; a live preview below shows the final normalized endpoint (append `#` at the end to keep your URL exact).
  - **API Key**: Select a saved key or add a new one.
  - **API Schema**: Select the request protocol (`OpenAI`, `OpenAI Responses`, `Anthropic`, `Google`, `Google Interactions`, `Mistral`, or `Ollama`).
  - **Model ID**: Enter the exact model identifier (e.g., `gpt-5.4-mini` or `qwen3:8b`).
  - **Input Modalities**: Select the input types your model supports (`Text`, `Image`, `Audio`, `Video`, `PDF`).
  - **Tools Usage Support**: Enable this if the model supports tool calling.
  - **Context Length** & **Maximum Output Length**: Set the model's context window and max output token limits.

<Callout type="info" title="Preset vs. Advanced Mode">
OpenRouter and SiliconFlow are already built into **Preset Mode**. Use **Advanced Mode** for **Ollama**, local runtimes, or third-party endpoints not listed in Preset Mode.
</Callout>

<Callout type="warning" title="Privacy & Capabilities">
Make sure the selected input modalities and tool-calling option match what your model actually supports, or requests may fail. Keep API keys private and never share them publicly.
</Callout>

### 2. System Prompt

System prompts are managed centrally on the **Prompts** page rather than edited inline on each assistant. Under the **System Prompt** tab:

- Pick the built-in **Default prompt** or any custom prompt from the dropdown menu.
- Use **New Prompt** or **Manage Prompts** at the bottom of the dropdown to create or edit prompts while checking the live preview.

See <DynamicLink href="/[lang]/docs/prompts">Prompts</DynamicLink> for guided templates and placeholders (`{DefaultSystemPrompt}`, `{SkillsPrompt}`, `{Date}`, `{OS}`, `{SystemLanguage}`, `{WorkingDirectory}`).

<Callout type="info" title="Cache-Friendly Dates">
Use `{Date}` instead of exact timestamps in custom prompts so the prompt prefix stays cache-friendly across messages.
</Callout>

### 3. Tools

Under the **Tools** tab, you can control tool permissions specifically for the selected assistant:

- **Tools** *(master toggle)*: Enables or disables tool calling for this assistant (also toggleable in chat with `Ctrl/⌘ + T`).
- **Follow global tool settings**: On by default so the assistant uses the global **Tools** page configuration. Turn this off to choose exactly which plugins and tools this assistant can use.

### 4. Advanced Settings

Under **Advanced Settings**, you can tune reliability, context limits, and model-specific options:

#### General & Context Controls

- **Request Timeout**: How long (in seconds) to wait for a response before timing out (default: `20`). Increase this for slower reasoning or local models.
- **Request retries**: How many times to retry recoverable failures (default: `5`; set `0` to disable, `-1` to keep retrying until stopped).
- **Screen Awareness Budget**: Caps how much screen content is read per perception (**Minimal (~1024)**, **Balanced (~4096, Recommended)** [default], **Detailed (~10240)**, **Ultimate (~40960)**, or **Unlimited (⚠️)**). Also adjustable in the chat window's assistant menu.
- **Context Compression Threshold**: Percentage (`5%–95%`, default: `80%`) of the model's context limit at which Everywhere automatically summarizes older history.
- **Maximum Context Rounds**: Caps how many recent conversation turns remain in context (`-1` for unlimited [default], `0` for current input only, up to `30`). Also adjustable in the chat window's assistant menu.

#### Protocol-Specific Options

Sampling and reasoning parameters appear in expandable sections matching the assistant's active **API Schema** (**OpenAI**, **OpenAI Responses**, **Anthropic**, **Google**, **Google Interactions**, or **Mistral**). Leaving an optional field blank omits it from requests:

- **OpenAI**: Include Reasoning Content, Thinking Type, Reasoning Effort, Temperature, Top-P, Expression Divergence (`presence_penalty`), Vocabulary Richness (`frequency_penalty`).
- **OpenAI Responses**: Reasoning Effort, Reasoning Summary (default: `auto`), Temperature, Top-P.
- **Anthropic Messages Settings**: Thinking Mode (Default / Disabled / Adaptive), Budget Tokens (default: `2048`), Thinking Effort, Prompt Cache (set to **Ephemeral** by default), Temperature, Top-P, Top-K.
- **Google**: Include Thoughts, Thinking Level, Thinking Budget, Temperature, Top-P, Top-K.
- **Google Interactions**: Include Thoughts, Thinking Level, Temperature, Top-P.
- **Mistral**: Include Reasoning Content, Reasoning Effort, Temperature, Top-P.

<Callout type="info">
Setting `Temperature` above `1.0` on some models may cause garbled output, and usually you should avoid changing both `Temperature` and `Top-P` at the same time. If a parameter triggers an error, clear it back to default.
</Callout>
