## 设置

### 终端路径

位于 **工具 > 终端 > 设置**。

自定义终端程序的路径（仅支持 PowerShell、zsh 和 bash）。

**留空**：自动选用系统默认终端（Windows 会优先使用已安装的 PowerShell 7+，未安装时使用 Windows PowerShell；macOS 默认使用 zsh；Linux 默认使用 bash）。

## 审批方式

出于安全考虑，**在终端中执行** 无法在 **工具 > 终端** 中设置为永久绕过审批。具体确认方式取决于聊天窗口当前的 **工具审批模式**：
* **请求批准**：每次运行命令前都会弹窗确认，可选择 **允许一次** 或 **当前聊天中允许**。
* **帮我批准**：交由你指定的审批助手结合上下文与风险自动审核。
* **完全访问权限**：无需确认直接运行。
