在应用内位于 **工具 > 内置 > 文件操作**。

<Callout type="error" title="安全性">
助手执行的文件操作**不可撤销**（删除操作会永久删掉文件，不会移入回收站）。在允许修改重要数据前，请先做好备份。
</Callout>

<Callout type="tip">
在 Windows 上，可将这些工具与 <DynamicLink href="/[lang]/docs/chat-tools/platform-specific/everything">Everything</DynamicLink>（或在 Linux 上与 <DynamicLink href="/[lang]/docs/chat-tools/platform-specific/fd-find">fd-find</DynamicLink>）搭配使用，实现极速本地文件搜索。如需处理 <code>.docx</code>、<code>.xlsx</code> 或 <code>.pptx</code> 文档，请使用 <DynamicLink href="/[lang]/docs/chat-tools/office">Office 办公套件</DynamicLink>。
</Callout>

## 设置与已批准的路径

### 已批准的路径

位于 **工具 > 文件操作 > 设置**。

你可以提前添加信任的文件夹路径规则（使用 `/` 分隔目录，并用 `**` 匹配任意层级的子文件夹，例如 `C:/Source/Everywhere/**`）。落入这些规则范围内的文件操作无需再逐次确认目录权限（删除非空文件夹等高风险操作除外）。

<Callout type="info" title="工作目录与快捷授权">
* **对话工作目录**：当前对话工作目录内的常规文件操作会自动获得批准。
* **弹窗快捷选项**：当操作位于已批准路径之外的文件时，弹窗提供 **总是允许上述路径**、**总是允许** 父文件夹或 **总是允许选择的文件夹…** 选项，点击即可保存为后续规则。
</Callout>
