## 设置

所有网络相关设置均位于 **工具 > 网络 > 设置**。

### 网络搜索引擎

选择 **网络搜索** 所使用的搜索引擎提供商：

* **Everywhere 云搜索**：基于 Everywhere Cloud 账号的云端搜索服务，支持配置 **搜索深度**、**限定领域**（通用 / 新闻）与 **时间范围**。
* **AnySearch** *(默认)*：支持选填 API 密钥和自定义 API 调用地址。
* **博查 (Bocha)**、**Brave**、**Jina**、**Serply**、**Tavily**、**UniFuncs**：需配置 API 密钥（可选自定义 API 调用地址）。
* **Google**：需配置 API 密钥和可编程 **搜索引擎 ID**。
* **SearXNG**：自托管元搜索引擎，只需填写 **API 调用地址**，无需 API 密钥。

### 在前台显示浏览器

开启后，**提取网页内容** 运行时会弹出并显示浏览器窗口，通常不建议开启。

**默认**：关闭

### 打开浏览器

打开提取网页所使用的浏览器，方便你提前登录常用网站，减少抓取网页时被识别为机器人的情况。如果本地没有可用的兼容浏览器，首次打开可能会自动下载，耗时取决于当前网络情况。
