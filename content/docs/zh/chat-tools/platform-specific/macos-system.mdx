仅在 **macOS** 上提供（位于 **工具 > 内置 > macOS 系统**）。让助手能够与 macOS 原生系统应用交互并执行系统级自动化任务。

<Callout type="info" title="系统授权提示">
首次通过助手访问“提醒事项”、“日历”、“邮件”、“备忘录”或其他应用时，macOS 可能会弹出自动化或隐私访问权限确认框。
</Callout>

## 功能

      <td>无</td>
