仅在 **Linux** 上提供（**默认关闭**）。作为 <DynamicLink href="/[lang]/docs/chat-tools/file-system">文件系统</DynamicLink> 内置工具的补充，借助 `fd` / `fdfind` 快速检索本地文件。

<Callout type="info" title="前置依赖">
使用前需先在系统中安装 <code>fd</code> 或 <code>fdfind</code>（例如 Debian/Ubuntu：<code>sudo apt install fd-find</code>；Fedora：<code>sudo dnf install fd-find</code>；Arch Linux：<code>sudo pacman -S fd</code>）。
</Callout>
