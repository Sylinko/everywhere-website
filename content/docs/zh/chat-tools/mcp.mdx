除了<DynamicLink href="/[lang]/docs/chat-tools">内置工具</DynamicLink>，Everywhere 还可以连接由外部 **MCP (Model Context Protocol)** 服务器提供的工具。支持两种传输方式：

- **Stdio** —— 启动一个本地进程，并通过标准输入/输出进行通信。
- **Streamable HTTP** —— 通过 HTTP 连接到远程服务器。

<Callout type="warning" title="SSE">
HTTP+SSE 支持已被弃用，推荐使用 Streamable HTTP。请为新服务器使用 Streamable HTTP。
</Callout>

在 **聊天工具** 页面打开 **MCP 服务器** 区域。你可以手动 **添加** 一个服务器，或从已有的 MCP 配置（JSON）中 **导入**。

## 添加服务器

点击 **添加** 打开配置对话框。带 `*` 的字段为必填项。

## 示例

### Stdio：文件系统服务器

通过 `npx` 运行官方文件系统服务器，授予对某个本地目录的访问权限。

<Table columnWidths={['30%', '70%']}>
  <thead>
    <tr><th>字段</th><th>值</th></tr>
  </thead>
  <tbody>
    <tr><td>名称</td><td>Filesystem</td></tr>
    <tr><td>协议</td><td>Stdio</td></tr>
    <tr><td>命令</td><td><code>npx</code></td></tr>
    <tr><td>命令行参数</td><td><code>-y</code> · <code>@modelcontextprotocol/server-filesystem</code> · <code>D:\Documents</code></td></tr>
  </tbody>
</Table>

<Callout type="warning" title="信任">
MCP 服务器会以你授予的权限运行，可能执行本地命令或通过网络发送数据。请只添加你信任的服务器。
</Callout>
