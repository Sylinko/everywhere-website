在主窗口左侧边栏打开 **助手** 页面，即可新建、排序、复制和配置各个 AI 助手。

<Callout type="info" title="测试连通性与管理助手">
- 点击右上角的 **测试连通性**，可以快速检查模型配置与网络是否正常（测试会发送一条简短请求，可能消耗极少额度）。
- 右上角工具栏支持 **复制** 或 **删除** 助手；在左侧列表中可直接 **拖拽排序**，同时会同步更新聊天窗口中 `Ctrl/⌘ + 1–9, 0` 切换助手的顺序。
</Callout>

## 基本信息

- **图标**：点击头像图标，可选择内置图标或 Emoji，并自定义颜色与背景色。
- **名称**：为助手起一个容易辨认的名字，方便在聊天窗口里快速切换。
- **描述**：写一句简短备注，记录这个助手的用途或特点。

## 配置标签页

每个助手下方分为四个标签页，分别用来配置模型、系统提示词、工具权限与高级选项。

### 1. 模型配置

顶部提供三种接入方式（完整对比见 <DynamicLink href="/[lang]/docs/models">模型与提供商</DynamicLink>）：

- **原生模式**（*Everywhere Cloud*）：官方托管服务，登录 Sylinko 通行证后直接选模型即可使用。
- **预设模式**（*主流平台直连*）：内置 OpenAI、Anthropic、Google、Mistral、DeepSeek、MoonshotAI、MiniMax、OpenRouter、硅基流动、智谱清言 / Z.ai 等 **14 家常用平台**。选好平台和 API 密钥后，就能直接从模型列表里挑选。
- **进阶模式**（*自定义协议接入*）：适合 **Ollama**、**LM Studio** 或其他自建/兼容接口：
  - **URL**：填写接口基础地址，下方会实时预览最终请求地址；在末尾加 `#` 可原样保留地址，不自动拼接路径。
  - **API 密钥**：选择已保存的密钥或新建密钥。
  - **API 协议**：选择接口协议（`OpenAI`、`OpenAI Responses`、`Anthropic`、`Google`、`Google Interactions`、`Mistral` 或 `Ollama`）。
  - **模型 ID**：输入模型标识（例如 `gpt-5.4-mini` 或 `qwen3:8b`）。
  - **输入模态**：勾选该模型支持接收的内容类型（文本、图片、音频、视频、PDF）。
  - **支持使用工具**：模型支持工具调用时开启。
  - **最大上下文** 与 **最大输出长度**：尽量按模型真实规格填写，这会影响上下文压缩等策略。

<Callout type="info" title="预设模式还是进阶模式？">
OpenRouter 和硅基流动已经内置在 **预设模式** 中。只有在使用 **Ollama**、本地服务或未收录的第三方接口时，才需要用 **进阶模式**。
</Callout>

<Callout type="warning" title="隐私与能力匹配">
请按模型真实能力勾选输入模态和工具支持，勾选了不支持的能力会导致对话报错。API 密钥属于敏感信息，请妥善保管。
</Callout>

### 2. 系统提示词

系统提示词统一放在 **提示词** 页面管理，不再单独存放在每个助手上。在 **系统提示词** 标签页中：

- 可以从下拉框选择内置的 **默认提示词**，或选用自己在 **提示词** 页面保存的任意提示词。
- 通过下拉框底部的 **创建提示词** 或 **管理提示词** 可快速新增与编辑，下方还能直接切换查看 **预览** 效果和 **原始** 文本。

关于提示词快速配置和占位符（`{DefaultSystemPrompt}`、`{SkillsPrompt}`、`{Date}`、`{OS}`、`{SystemLanguage}`、`{WorkingDirectory}`）的详细说明，请参阅 <DynamicLink href="/[lang]/docs/prompts">提示词</DynamicLink>。

<Callout type="info" title="占位符小贴士">
自定义提示词建议使用 `{Date}` 日期占位符，不要放精确到秒的时间戳，这样更容易命中模型的提示词缓存。
</Callout>

### 3. 工具

在 **工具** 标签页中，可以为当前助手单独设置工具权限：

- **工具** *（顶部总开关）*：控制该助手能否调用工具（聊天窗口内也可按 `Ctrl/⌘ + T` 快速开关）。
- **跟随全局工具设置**：默认开启，表示沿用 **工具** 页面的全局开关；关闭后，就能为这个助手单独挑选启用哪些插件和具体工具。

### 4. 高级设置

在 **高级设置** 标签页中，可以按需微调网络重试、上下文策略和协议参数：

#### 通用与上下文控制

- **请求超时时长**：单次等待回复的超时上限（单位为秒，默认 `20` 秒），推理较慢的模型或本地模型可以适当调大。
- **请求重试次数**：遇到网络波动等可恢复错误时的最大重试次数（默认 `5` 次；填 `0` 关闭，填 `-1` 会一直重试直到手动停止）。
- **屏幕感知预算**：限制每次读取屏幕内容时的 Token 估算上限（**最小 (~1024)**、**平衡 (~4096，推荐)** [默认]、**详细 (~10240)**、**极致 (~40960)**、**无限制 (⚠️)**），聊天窗口的助手菜单里也能随时调整。
- **上下文压缩阈值**：当上下文用量达到模型 **最大上下文** 的该比例时（`5%–95%`，默认 `80%`），自动总结并压缩早期对话。
- **最大上下文轮次**：限制随请求发送的最近对话轮次（`-1` 为不限制 [默认]，`0` 为只发当前这一句，最高 `30`），同样可在聊天窗口的助手菜单中实时调整。

#### 协议专属选项

采样和深度思考参数按助手选用的 **API 协议** 折叠展示（对应 **OpenAI**、**OpenAI Responses**、**Anthropic Messages 设置**、**Google**、**Google Interactions** 和 **Mistral**）。留空的选项不会放进请求里：

- **OpenAI**：包含推理内容、思考类型、推理强度、Temperature、Top-P、表述发散度 (`presence_penalty`)、词汇丰富度 (`frequency_penalty`)。
- **OpenAI Responses**：推理强度、推理摘要（默认 `auto`）、Temperature、Top-P。
- **Anthropic Messages 设置**：思考模式（默认 / 关闭 / 自适应）、思考预算（默认 `2048`）、思考强度、提示缓存（默认 **临时缓存 (Ephemeral)**）、Temperature、Top-P、Top-K。
- **Google**：包含思考过程、思考等级、思考预算、Temperature、Top-P、Top-K。
- **Google Interactions**：包含思考过程、思考等级、Temperature、Top-P。
- **Mistral**：包含推理内容、推理强度、Temperature、Top-P。

<Callout type="info">
部分模型将 `Temperature` 设得过高（如大于 `1.0`）可能出现输出乱码，通常也不建议同时修改 `Temperature` 和 `Top-P`。若某个参数引发请求报错，清空还原即可。
</Callout>
