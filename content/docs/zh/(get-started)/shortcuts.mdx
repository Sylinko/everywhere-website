## 全局与窗口快捷键

| 功能 | Windows / Linux | macOS | 备注 |
| :--- | :--- | :--- | :--- |
| **呼出聊天窗口** | 自定义 | 自定义 | 默认为 `Ctrl + Shift + E`（Windows 支持绑定 `Copilot` 键） |
| **选择视觉元素** | 自定义 | 自定义 | 可在 **设置 > 快捷键** 中修改 |
| **捕获屏幕截图** | 自定义 | 自定义 | 可在 **设置 > 快捷键** 中修改 |
| **切换助手** | `Ctrl` + `1`–`9`, `0` | `⌘` + `1`–`9`, `0` | 也可把鼠标停在助手图标上滚动滚轮切换 |
| **新建对话** | `Ctrl` + `N` | `Ctrl` + `N` | 处于已有对话中时可用 |
| **置顶固定** | `Ctrl` + `D` | `Ctrl` + `D` | 切换聊天窗口置顶状态 |
| **关闭 / 隐藏窗口** | `Ctrl` + `W` | `Ctrl` + `W` | 关闭并隐藏悬浮聊天窗口 |
| **逐级取消 / 隐藏** | `Esc` | `Esc` | 优先关闭聊天内搜索，其次取消消息编辑，最后隐藏窗口 |
| **切换临时聊天** | `Ctrl` + `G` | `⌘` + `G` | 在临时聊天与常规聊天（保留记录）间切换 |
| **展开 / 收起历史** | `Ctrl` + `H` | `⌘` + `H` | 打开或收起聊天窗口历史记录面板 |
| **搜索历史对话** | `Ctrl` + `Shift` + `F` | `⌘` + `Shift` + `F` | 在历史记录面板中搜索历史对话 |
| **聊天内查找** | `Ctrl` + `F` | `⌘` + `F` | 搜索当前对话内容（`Enter` 下一条、`Shift+Enter` 上一条、`Esc` 关闭） |
| **工具调用开关** | `Ctrl` + `T` | `⌘` + `T` | 快速开启或关闭当前助手的工具调用（需模型支持） |

你可以前往主界面左侧边栏的 **设置 > 快捷键** 修改可自定义的全局快捷键。

## Linux 快捷键

Hyprland 支持全局快捷键；Plasma 5 使用 KGlobalAccel，Plasma 6、GNOME 和支持 GlobalShortcuts portal 的 X11 桌面需要系统授权。Niri 需要在桌面配置中手动绑定启动 Everywhere 的命令，仅在应用内录制快捷键不会创建该绑定。

截图和视觉元素选择是否可用取决于桌面环境，请参阅 [Linux 兼容性说明](/zh/docs/linux)。

## 发送消息快捷键

在 **设置 > 聊天窗口 > 发送消息** 中，你可以选择用 **Enter**（默认）还是 **Ctrl+Enter**（macOS 为 `⌘+Enter`）发送消息。配合 **忙碌时默认发送方式**（**排队** 或 **尽快发送**），它也同时决定了助手回复时在 **加入排队** 与 **立即引导** 之间切换的快捷键：

| 操作 | `Enter` 模式 *（默认）* | `Ctrl+Enter` 模式 |
| :--- | :--- | :--- |
| **发送消息** *（或按默认忙碌发送方式）* | `Enter` | `Ctrl + Enter` / `⌘ + Enter` |
| **换行** | `Shift + Enter` | `Enter` |
| **使用另一种忙碌发送方式** *（默认排队时立即引导，反之亦然）* | `Ctrl + Enter` / `⌘ + Enter` | `Ctrl + Shift + Enter` / `⌘ + Shift + Enter` |

## 托盘图标与 Copilot 键

<Callout type="info" title="托盘图标操作">
**单击**系统托盘图标可快速呼出聊天窗口，**双击**可打开主界面，**右键单击**可打开托盘菜单（**打开聊天窗口**、**打开主窗口**、**聊天窗口快捷键** 开关、**退出**）。
</Callout>

<Callout type="info" title="Copilot 快捷键呼出">
如果你的 Windows 键盘带有独立的 `Copilot` 键，可以直接将它录制为呼出聊天窗口的快捷键。
</Callout>
