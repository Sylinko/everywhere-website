## 付款与账号

### 我订阅了 ChatGPT Plus/Team/Pro 或类似服务，为什么提示我余额不足？

ChatGPT Plus/Team/Pro、Google AI Pro 等会员订阅仅用于各自的网页版和官方 App，与开发者 API 服务分开计费。

**使用自带密钥（BYOK）时，需要为 API 服务单独充值；或者登录 Sylinko 通行证直接使用 Everywhere Cloud。**

## 模型提供商

### 使用 Ollama、LM Studio 或未内置的兼容服务时如何配置？

可以先查看 **助手** 页面的 **预设模式**：里面已经内置了 OpenRouter、硅基流动、Mistral、智谱清言 / Z.ai、OpenAI、Anthropic、Google、DeepSeek、MoonshotAI、MiniMax 等 14 家常用平台。

如果你使用的是 **Ollama**、**LM Studio** 或未收录的兼容接口，请切换至 **进阶模式**（*自定义协议接入*），选择对应的 **API 协议**，填入接口地址和模型 ID，并通过输入框下方的实时预览确认最终请求地址。

详情请参阅 <DynamicLink href="/[lang]/docs/models#local-and-custom-endpoints">模型与提供商 — 本地与自定义端点</DynamicLink>。

### 为什么我使用的（非官方支持的）模型提供商无法正常工作？

**Everywhere** 内置支持 **Everywhere Cloud** 及 14 家 **预设模式** 提供商，我们会重点保障这些通道的兼容性与稳定性。

对于其他兼容 OpenAI / Anthropic / Google / Mistral / Ollama 协议的服务，你可以通过 **进阶模式** 手动配置（参阅 <DynamicLink href="/[lang]/docs/models#local-and-custom-endpoints">模型与提供商</DynamicLink>）。由于第三方和自建服务的接口实现差异较大，我们无法逐一测试所有非内置接口。如果遇到报错，请先核对输入框下方的实时地址预览并联系服务提供方，或换用内置预设与云服务模型。

### AI 没有给出任何回答

提问后如果没有收到回答（但界面的状态提示能正常出现），通常是进阶模式下的 **URL** 或 **API 协议** 没填对。

最常见的问题是 OpenAI 兼容接口漏掉了末尾的 `/v1`（例如把 `https://api.example.com/v1` 写成了 `https://api.example.com`）。

<Callout type="tip" title="查看实时地址预览">
1. 如果你的服务商在 **预设模式** 列表里，直接使用预设即可，不用手填地址。
2. 在 **进阶模式** 下，输入后请留意 **URL** 输入框下方的实时预览地址；如果希望按原样发送地址（不自动拼接版本号路径），在末尾加上 `#` 即可。

### 为什么无法读取图片？

**并不是所有大模型都支持图片输入。**

如果当前助手用的是纯文本模型，或在进阶模式下没有在 **输入模态** 里勾选 **支持图像输入**，发送图片时会提示：`“当前助手不支持图片输入。”`

请切换到支持视觉的模型（进阶模式需确认已勾选 **支持图像输入**）。另外，如果助手需要通过 **查看图像** 工具读取磁盘上的图片文件，请确保 **工具 > 必备 > 查看图像** 已开启，并检查 **设置 > 系统助手 > 图像理解子助手** 配置。

### 为什么无法使用网络搜索？

通过 API 调用模型时，默认不自带网页版那种联网搜索插件。Everywhere 通过内置的 **网络** 工具为助手提供联网能力：

- **Everywhere 云搜索（推荐）**：登录账号后可直接使用账户积分或[订阅计划](/zh/pricing)包含的每月免费搜索次数，开箱即用。
- **自定义搜索引擎**：前往主窗口的 **工具 > 网络** 页面填写 Google、Brave、Tavily、博查等外部搜索引擎的 API 密钥。

详情请参阅 <DynamicLink href="/[lang]/docs/chat-tools/web">工具 — 网络</DynamicLink>。

## 软件使用与权限

### 为什么我无法呼出悬浮聊天框？

1. **快捷键冲突或未开启**：设置的快捷键可能与截图工具、输入法等软件冲突，或者在引导/托盘菜单中被关掉了。
   - **解决方法**：检查 **设置 > 快捷键**（或右键托盘图标查看 **聊天窗口快捷键** 是否勾选），更换一组不冲突的快捷键。
2. **管理员权限窗口（Windows）**：当当前焦点处于以管理员身份运行的程序（如任务管理器、部分安装程序）上时，Windows 权限隔离会阻止普通程序与其交互。
   - **解决方法**：前往主窗口 **设置 > 通用**，开启 **以服务的方式安装**，开启后无需把整个客户端设为管理员即可正常呼出和操作。
3. **macOS 辅助功能与录屏权限**：请在 **系统设置 > 隐私与安全性** 中为 Everywhere 开启 **辅助功能** 与 **录屏与系统录音** 权限，否则无法注册全局快捷键、划词或读取屏幕内容。
4. **Linux 桌面权限与快捷键绑定**：KDE Plasma 6 / GNOME 需在系统弹窗中授予全局快捷键权限；Niri 需在合成器配置里手动绑定启动命令。详见 <DynamicLink href="/[lang]/docs/linux">Linux 兼容性说明</DynamicLink>。

### 终端和文件等工具怎么控制自动批准？

Everywhere 在聊天窗口底部工具栏直接提供了三档 **工具审批** 模式：

- **请求批准** *（默认）*：执行终端命令、修改工作区外文件或调用 MCP 工具等敏感操作前会弹出确认卡片，你可以选择 **允许一次**、**当前聊天中允许**、**总是允许** 或拒绝。
- **帮我批准**：由指定的审批助手（可在 **设置 > 系统助手 > 工具审批** 中设置）结合当前任务判断风险并自动决策；高风险操作仍会自动拦截。
- **完全访问权限**：所有已开启的工具无需确认直接运行（界面顶部会给出风险提示条，确认风险可控后再开启）。

### AI 正在回复时能继续发消息吗？

可以。前往 **设置 > 聊天窗口 > 忙碌时默认发送方式**，可设置默认是 **排队**（等这轮回复完自动发出去）还是 **尽快发送**（立刻插话引导当前回复，输入栏按钮提示为 **立即引导**）。输入时也能用快捷键临时切换另一种方式（`Enter` 模式下按 `Ctrl/⌘ + Enter`，`Ctrl+Enter` 模式下按 `Ctrl/⌘ + Shift + Enter`），还可以在输入框上方随时修改、撤回或删除排队中的消息。
