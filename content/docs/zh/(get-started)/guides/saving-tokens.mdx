每次向 AI 提问都会消耗 Token，直接影响你的 API 账单或 Everywhere Cloud 积分。调整好几个关键设置，就能在保证回答质量的同时省下大量开销。

## 屏幕感知与上下文范围

屏幕感知能让 Everywhere 看懂当前界面，但如果窗口结构复杂，附带的界面信息也会增加不少输入 Token。

在聊天窗口底部点击 **选择助手** 图标，打开其中的 **高级设置** 菜单（在主窗口 **助手 > 高级设置** 里也能找到同样的选项）：

### 屏幕感知预算

- **作用**：限制每次读取屏幕内容时的估算 Token 上限（可选 **最小 (~1024)**、**平衡 (~4096，推荐)**、**详细 (~10240)**、**极致 (~40960)** 或 **无限制 (⚠️)**）。
- **建议**：日常使用选 **平衡 (~4096，推荐)** 即可；如果只是识别简单按钮或少量文字，调成 **最小 (~1024)** 会更省。

<Callout type="tip">
这里设置的是估算上限，实际发送的 Token 数量会随当前窗口的复杂度略有浮动。
</Callout>

### 最大上下文轮次

- **作用**：限制随请求一起发送的最近对话轮数（`-1` 为不限制，`0` 为只发当前这一句，最高 `30`）。
- **建议**：多步骤连续任务保持 `-1`（配合下方的自动压缩即可）；如果只是单次翻译或零散问答，调小轮次上限能明显减少重复上下文。

### 自动添加元素

在 **设置 > 聊天窗口** 中，**自动添加元素** 默认处于关闭状态。保持关闭可以避免每次打开聊天窗口都自动附带屏幕信息；确实需要 AI 看屏幕时，再从回形针按钮里选择视觉元素或截图即可。

## 上下文压缩与用量查看

对话越聊越长时，历史记录会不断累计。你可以通过以下方式控制上下文体积：

- **上下文使用情况**：悬停或点击发送按钮旁的环形用量指示器打开 **上下文使用情况** 面板，可以随时查看已用 Token 数、占比以及 **缓存输入** 命中情况。
- **自动压缩**：在 **助手 > 高级设置** 中调整 **上下文压缩阈值**（`5%–95%`，默认 `80%`）。对话用量达到该比例时，Everywhere 会自动把早期内容压缩成精简摘要。
- **手动压缩与新建对话**：随时点击 **上下文使用情况** 面板里的 **压缩上下文** 按钮主动整理历史，或者切换新话题时按 `Ctrl + N` 开启新对话。

## 提示词缓存与系统提示词

Everywhere 会在同一段对话期间尽量保持前导系统提示词与工具列表不变，方便服务商复用提示词缓存：

- **使用 `{Date}`**：在自定义提示词中使用按天变化的 `{Date}`，避免时间戳每句话都变而导致缓存失效。
- **保持提示词精简**：定期在 **提示词** 页面清理重复或不再需要的规则。
- **Anthropic 提示缓存**：使用 `Anthropic` 协议时，建议在 **助手 > 高级设置 > Anthropic Messages 设置** 中保持 **提示缓存** 开启（默认 **临时缓存 (Ephemeral)**）。
- **并行工具调用**：内置 `{DefaultSystemPrompt}` 已自带并行调用指引，模型会尽量在一次回复里同时发起多个独立工具调用，减少多余的来回轮次。

## 按助手裁剪工具与 `Ctrl/⌘ + T`

每个开启的工具都会把它的名称、用途和参数说明一起传给模型：

- **纯文字对话先关掉工具**：写作、翻译或头脑风暴不需要调用工具时，直接在聊天窗口按 `Ctrl/⌘ + T`（或在助手菜单里关闭 **工具** 开关），即可省去全部工具描述开销。
- **给不同助手配不同的工具**：在 **助手 > 工具** 中关闭 **跟随全局工具设置**，就能为某个专属助手只开启它真正用得到的插件或工具（在聊天窗口的助手菜单 > **工具** 里也能随时开关）。
