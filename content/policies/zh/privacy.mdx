本隐私声明说明，您使用 Sylinko Inc.（以下简称“我们”）的服务（以下简称“服务”）时，我们可能如何以及为何访问、收集、存储、使用和/或共享（统称“处理”）您的个人信息，包括您进行以下活动时：
- 下载并使用我们的桌面应用程序 Everywhere，或使用我们提供的任何链接至本隐私声明的其他服务；

## 要点摘要 [#summary-of-key-points]

**我们处理哪些个人信息？** 当您访问、使用或浏览服务时，我们可能会处理个人信息。具体处理哪些信息取决于您如何与我们和服务互动、您作出的选择，以及您使用的产品和功能。详见[您提供的信息及我们自动收集的信息](#information-you-provide--we-collect-automatically)。

**我们是否处理敏感个人信息？** 某些司法管辖区可能将部分信息视为“特殊”或“敏感”信息，例如种族或民族出身、性取向和宗教信仰。我们不处理敏感个人信息。

**我们是否从第三方收集信息？** 我们可能从公共数据库、营销合作伙伴、社交媒体平台和其他外部来源收集信息。详见[从其他来源收集的信息](#information-collected-from-other-sources)。

**我们如何处理您的信息？** 我们处理信息是为了提供、改进和管理服务，与您沟通，维护安全和防止欺诈，以及遵守法律。经您同意，我们也可能为其他目的处理您的信息。我们仅在具有有效法律依据时处理您的信息。详见[我们如何处理您的信息](#2-how-do-we-process-your-information)。

**我们在何种情况下、与哪些类型的主体共享个人信息？** 我们可能在特定情况下与特定类别的第三方共享信息。详见[我们何时与谁共享您的个人信息](#4-when-and-with-whom-do-we-share-your-personal-information)。

**我们如何保障信息安全？** 我们已建立适当的组织和技术流程及程序，以保护您的个人信息。但无法保证任何互联网电子传输或信息存储技术 100% 安全。因此，我们不能承诺或保证黑客、网络犯罪分子或其他未经授权的第三方无法突破我们的安全措施，不当收集、访问、窃取或修改您的信息。详见[我们如何保障您的信息安全](#11-how-do-we-keep-your-information-safe)。

**您享有哪些权利？** 根据您所在的地理位置，适用的隐私法律可能赋予您与个人信息有关的特定权利。详见[您享有哪些隐私权](#13-what-are-your-privacy-rights)。

**您如何行使权利？** 最简便的方式是发送电子邮件至 [contact@sylinko.com](mailto:contact@sylinko.com)，或以其他方式联系我们。我们会依照适用的数据保护法律审议并处理每一项请求。

## 1. 我们收集哪些信息？ [#1-what-information-do-we-collect]

我们收集您向我们提供的信息，以及您使用服务时自动收集的信息。

### 您提供的信息及我们自动收集的信息 [#information-you-provide--we-collect-automatically]

**个人及账户信息**
- **账户资料：** 姓名、电子邮件地址、联系信息、账单地址，以及您自愿提供的其他个人资料。
- **社交媒体登录数据：** 如果您使用社交媒体账户（如 Google 或 GitHub）注册，我们会从该提供商获取基本资料（姓名、电子邮件地址和头像）。
- **支付数据：** 我们使用 Stripe 提供支付、分析及其他业务服务。Stripe 会收集可识别连接其服务的设备的信息，并用这些信息运营和改进它向我们提供的服务，包括检测欺诈。有关 Stripe 的更多信息，请参阅 [Stripe 隐私政策](https://stripe.com/privacy)。
- **敏感信息：** 我们不处理敏感信息。

**Everywhere 应用程序数据（桌面端）**

*桌面应用程序采用“本地优先”的隐私架构，这一点尤为重要。*
- **桌面上下文和屏幕数据：** 为提供能感知上下文的协助，Everywhere 可能通过截图或无障碍 API 处理您屏幕上显示的内容。**此处理在您的设备本地进行。** 除非您明确触发了需要云端处理的功能（例如向某个大型语言模型发送特定截图），否则我们不会将原始屏幕录像或完整截图上传到我们的服务器。
- **聊天记录及设置：** 默认存储在您的设备上。如果您启用云同步，我们会在服务器上存储加密数据以实现同步。
- **遥测及诊断：** 我们使用 **Sentry** 监测性能和稳定性。为保护您的隐私，我们采取以下措施：
    - **清除个人身份信息（PII）：** 崩溃报告离开设备之前，我们会自动过滤并移除可识别个人身份的信息。
    - **匿名标识符：** 我们使用经过哈希处理的随机标识符，无法通过逆向推算识别您个人。
    - **不访问代码：** 诊断数据仅包含经过混淆处理的调用栈信息和系统指标；我们绝不收集您的源代码、提示词或本地项目文件。
- **推送通知：** 我们可能请求向您发送与账户或功能有关的通知。您可以在设备设置中选择退出。

**服务使用及设备数据**
- **日志和使用数据：** IP 地址、浏览器或设备特征、操作系统、语言偏好以及使用时间戳。
- **设备数据：** 设备 ID、硬件型号及系统配置。
- **位置数据：** 根据 IP 地址推测的大致位置（国家或城市）。我们不收集精确的 GPS 数据。

### 从其他来源收集的信息 [#information-collected-from-other-sources]

为更好地向您提供相关营销信息、优惠及服务，并更新我们的记录，我们可能从其他来源获取您的信息，例如公共数据库、联合营销合作伙伴、联盟营销计划、数据提供商、社交媒体平台和其他第三方。这些信息包括电子邮件地址、意向数据（或用户行为数据）、互联网协议（IP）地址、社交媒体资料和网址，以及定制的个人资料，用于定向广告和活动推广。

**数据控制者：** 就欧盟《通用数据保护条例》（GDPR）和英国 GDPR 而言，Sylinko Inc. 是您个人信息的数据控制者。

## 2. 我们如何处理您的信息？ [#2-how-do-we-process-your-information]

**我们处理您个人信息的原因取决于您与服务的互动方式，包括：**
- **协助创建账户、验证身份及管理用户账户。** 我们可能处理您的信息，以便您创建和登录账户并维持账户正常运行。（法律依据：履行合同）
- **向用户提供服务并协助交付服务。** 我们可能处理您的信息，以提供您请求的服务。（法律依据：履行合同）
- **答复用户询问并提供支持。** 我们可能处理您的信息，以答复询问并解决您在所请求的服务中可能遇到的问题。（法律依据：履行合同或合法利益）
- **向您发送管理信息。** 我们可能处理您的信息，以发送产品和服务详情、条款和政策变更以及其他类似信息。（法律依据：履行合同或合法利益）
- **履行和管理您的订单。** 我们可能处理您的信息，以履行和管理您通过服务办理的订单、付款、退货和换货。（法律依据：履行合同）
- **征求反馈。** 必要时，我们可能处理您的信息，以征求反馈，并就您使用服务的情况与您联系。（法律依据：合法利益）
- **发送营销和推广信息。** 如果符合您的营销偏好，我们可能为营销目的处理您发送给我们的个人信息。您可随时退订营销邮件。（法律依据：同意或合法利益）
- **保护我们的服务。** 我们可能处理您的信息，以维护服务安全，包括监测和防止欺诈。（法律依据：合法利益或法定义务）
- **识别使用趋势。**
  - 我们可能处理有关您如何使用服务的信息，以更好地了解服务的使用情况并加以改进。（法律依据：合法利益）
  - 对于与 Google Analytics 相关的数据处理，法律依据为您的明确同意。
- **确定营销和推广活动的效果。** 我们可能处理您的信息，以便了解如何向您提供与您最相关的营销和推广活动。（法律依据：合法利益）
- **维护或保护个人的重大切身利益。** 必要时，我们可能处理您的信息以维护或保护个人的重大切身利益，例如防止伤害。（法律依据：重大切身利益）
- **监督许可合规情况。** 我们可能处理 IP 地址、激活记录等信息，以识别对商业许可证的未经授权使用，并核实组织订阅资格。（法律依据：合法利益或履行合同）

## 3. 我们依据哪些法律基础处理您的个人信息？ [#3-what-legal-bases-do-we-rely-on-to-process-your-personal-information]

我们仅在具有有效法律依据时处理您的个人信息。根据您所在的位置和与服务的互动方式，我们依赖以下法律依据：

- **同意：** 您已准许我们为特定目的使用您的信息。您可随时撤回同意。
- **履行合同：** 为履行我们对您承担的合同义务（例如提供您请求的服务）。
- **合法利益：** 为我们的合法商业利益，例如改进服务、开展营销、维护安全和防止欺诈，但这些利益不得优先于您的基本权利和自由。
- **法定义务：** 为遵守适用的法律、法规或法律要求（例如税法或执法机关的要求）。
- **重大切身利益：** 为保护您或其他人的重大切身利益（例如在紧急情况下）。

*有关您所在地区的具体权利（如欧盟及英国的 GDPR、加拿大的 PIPEDA），请参阅下文的[“您享有哪些隐私权？”](#13-what-are-your-privacy-rights)。*

## 5. 我们是否使用 Cookie 和其他跟踪技术？ [#5-do-we-use-cookies-and-other-tracking-technologies]

我们使用 Cookie 及类似跟踪技术（例如跟踪像素、SDK 和本地存储）来提供、保护和改进服务。我们将这些细节集中在此说明，以便您了解我们如何跟踪数据。

**我们使用的技术类型：**
- **严格必要的技术：** 服务运行所必需，例如 Sylinko Passport 的身份验证令牌。这些技术无法禁用。
- **功能和偏好：** 用于记住您的设置（例如主题偏好、语言）并提供增强功能。
- **营销：** 我们可能使用跟踪像素衡量营销活动的效果。我们不会将这些数据出售给第三方。

**如何控制 Cookie：**
- **浏览器设置：** 您可以设置浏览器，拒绝全部或部分浏览器 Cookie，或在网站设置或访问 Cookie 时提醒您。
- **请勿跟踪：** 我们的系统目前可能不响应浏览器的“请勿跟踪”（DNT）信号，但我们尊重您在应用设置中明确作出的退出选择。

- **提示：** Google Analytics（GA）等此类技术默认关闭，仅在您明确选择启用后才会启动。

## 6. 我们是否提供基于人工智能的产品？ [#6-do-we-offer-artificial-intelligence-based-products]

是的，我们的服务包含 AI 驱动的功能。整合这些技术时，我们优先考虑您的隐私。

**AI 技术的使用**

我们使用第三方 AI 服务提供商（如 Anthropic、DeepSeek，以及设置中列出的其他提供商）为 AI 功能提供支持。我们仅为生成回复而与这些提供商共享您的输入及上下文。

**API 中转服务及数据隐私**

当您使用 API 中转服务时，您的提示词和 AI 回复会经由我们的服务器传输至第三方模型提供商。
- **Sylinko 不用于训练：** 我们不使用您的提示词、屏幕上下文或输出来训练自己的模型。但第三方提供商如何使用您的数据受其自身政策约束，例如 [OpenAI 隐私政策](https://openai.com/privacy)和 [Anthropic 隐私政策](https://www.anthropic.com/privacy)。
- **不永久存储内容：** 我们不永久存储您的提示词或生成的回复内容。
- **仅保留元数据：** 我们只为计费和防止滥用保留元数据，例如令牌（token）用量、时间戳和模型类型。

## 7. 文档反馈与 GitHub Discussions [#7-documentation-feedback--github-discussions]

文档网站的反馈功能允许您为页面评分、提交评论。使用此功能时：

**反馈的运作方式：**
- 您的反馈（包括评分及任何评论文字）将通过我们的 GitHub App 发送到 **GitHub Discussions**，这是由 GitHub, Inc.（微软旗下公司）托管的公开论坛。
- 提交反馈即表示您知悉并同意，您的反馈内容将在我们 GitHub 仓库的 Discussions 页面上公开显示。

**数据处理及向第三方披露：**
- **公开可见：** 通过这一机制提交的所有反馈都可在 GitHub 上公开访问。请勿在反馈中包含个人信息或敏感信息。
- **第三方处理：** GitHub 是这些信息的数据处理者。GitHub 对您数据的收集和处理受 [GitHub 隐私声明](https://docs.github.com/en/site-policy/privacy-policies/github-general-privacy-statement)约束。
- **数据存储地：** GitHub 的服务器主要位于美国。提交反馈即表示您同意将反馈数据传输至美国。
- **无需账户：** 您无需创建 Sylinko 账户即可提交反馈。但您的反馈将与页面 URL 和时间戳关联。

**您的权利：**
- 根据 GDPR、CCPA 和《个人信息保护法》（PIPL），您有权请求删除反馈。但鉴于 GitHub Discussions 的公开性质和平台运作方式，删除请求须由 Sylinko 与 GitHub 双方协调处理。
- 如需移除您已提交的反馈，请通过 [contact@sylinko.com](mailto:contact@sylinko.com) 联系我们，并提供相应的 GitHub Discussion URL。

**跨境数据传输（遵守 GDPR 和《个人信息保护法》）：**
- 您提交反馈时，您的数据将传输至 GitHub 位于美国的服务器。
- 就国际数据传输而言，我们依赖 GitHub 对标准合同条款（SCC）及其他适当保障措施的遵守。
- 对中国境内受《个人信息保护法》保护的用户，使用反馈功能即表示您明确同意通过 GitHub 平台将您的反馈数据跨境传输至美国。

## 8. 我们如何处理您的社交账户登录？ [#8-how-do-we-handle-your-social-logins]

您可以使用 Google 或 GitHub 等第三方社交媒体账户资料注册和登录服务。如果您选择这样做，我们将从相应的社交媒体提供商处收到您的部分个人资料。收到的信息因提供商而异，通常包括您的姓名、电子邮件地址、好友列表和头像，以及您选择在该平台公开的其他信息。

我们仅将收到的信息用于本隐私声明所述目的，或在相关服务上另行向您明确说明的目的。我们无法控制第三方社交媒体提供商将您的个人信息用于其他用途，也不对此负责。我们建议您阅读其隐私声明，了解其如何收集、使用和共享您的个人信息，以及如何在其网站和应用中设置隐私偏好。

## 9. 您的信息是否会跨境传输？ [#9-is-your-information-transferred-internationally]

我们的服务器位于美国。无论您身在何处，您的信息都可能被传输至美国及其他国家，并在这些国家处理。

我们采取适当的保障措施，例如欧盟委员会的标准合同条款（SCC），以确保您的个人信息在跨境传输时仍依照适用法律受到保护。

## 10. 我们将您的信息保留多久？ [#10-how-long-do-we-keep-your-information]

我们仅在实现本隐私声明所述目的所必要的期限内保留您的个人信息，除非法律要求或允许更长的保留期限（如税务、会计或其他法律要求）。本声明所列目的均不要求我们在用户账户终止后保留其个人信息超过六（6）个月，但法律要求更长保留期的除外（例如财务及交易记录须保留 7 年）。

当我们不再有持续且合法的业务需要来处理您的个人信息时，我们会将其删除或匿名化。如果无法这样做（例如个人信息已存入备份档案），我们会安全地存储这些信息，并将其隔离，不再进一步处理，直到可以删除为止。

## 11. 我们如何保障您的信息安全？ [#11-how-do-we-keep-your-information-safe]
