## 要点摘要 [#summary-of-key-points]

**我们处理哪些个人信息？** 当您访问、使用或浏览服务时，我们可能会处理个人信息。具体处理哪些信息取决于您如何与我们和服务互动、您作出的选择，以及您使用的产品和功能。详见[您提供的信息及我们自动收集的信息](#information-you-provide--we-collect-automatically)。

**我们是否处理敏感个人信息？** 某些司法管辖区可能将部分信息视为“特殊”或“敏感”信息，例如种族或民族出身、性取向和宗教信仰。开设账户不要求提供这类信息；您主动提交给 AI 或客服的内容可能包含此类信息。

**我们如何处理您的信息？** 我们处理信息是为了提供、改进和管理服务，与您沟通，维护安全和防止欺诈，以及遵守法律。经您同意，我们也可能为其他目的处理您的信息。我们仅在具有有效法律依据时处理您的信息。详见[我们如何处理您的信息](#2-how-do-we-process-your-information)。

**我们在何种情况下、与哪些类型的主体共享个人信息？** 我们可能在特定情况下与特定类别的第三方共享信息。详见[我们何时与谁共享您的个人信息](#4-when-and-with-whom-do-we-share-your-personal-information)。

**我们如何保障信息安全？** 我们已建立适当的组织和技术流程及程序，以保护您的个人信息。但无法保证任何互联网电子传输或信息存储技术 100% 安全。因此，我们不能承诺或保证黑客、网络犯罪分子或其他未经授权的第三方无法突破我们的安全措施，不当收集、访问、窃取或修改您的信息。详见[我们如何保障您的信息安全](#11-how-do-we-keep-your-information-safe)。

**您享有哪些权利？** 根据您所在的地理位置，适用的隐私法律可能赋予您与个人信息有关的特定权利。详见[您享有哪些隐私权](#13-what-are-your-privacy-rights)。

**您如何行使权利？** 最简便的方式是发送电子邮件至 [contact@sylinko.com](mailto:contact@sylinko.com)，或以其他方式联系我们。我们会依照适用的数据保护法律审议并处理每一项请求。

## 1. 我们收集哪些信息？ [#1-what-information-do-we-collect]

我们收集您向我们提供的信息，以及您使用服务时自动收集的信息。

### 您提供的信息及我们自动收集的信息 [#information-you-provide--we-collect-automatically]

**个人及账户信息**
- **账户资料：** 姓名、电子邮件地址、联系信息、账单地址，以及您自愿提供的其他个人资料。
- **社交媒体登录数据：** 如果您使用社交媒体账户（如 Google 或 GitHub）注册，我们会从该提供商获取基本资料（姓名、电子邮件地址和头像）。
- **支付数据：** 在普通结账通道（包括支付宝）中，Sylinko 是商户，Stripe 作为处理者代表我们处理支付。在适用地区，若结账页面标注“Sold through Link”（Stripe Managed Payments），Stripe 或其关联方是记录商户，并就该笔交易、开票及税务担任独立数据控制者。仅使用 Link 钱包不会改变商户身份。Stripe 会收集可识别连接其服务的设备的信息，并用这些信息运营和改进它向我们提供的服务，包括检测欺诈。Stripe 也会为自身的反欺诈和法定合规目的，作为控制者处理信息。有关 Stripe 的更多信息，请参阅 [Stripe 隐私政策](https://stripe.com/privacy)。
- **敏感信息：** 开设账户不要求您提供敏感信息。

**Everywhere 应用程序数据（桌面端）**

*桌面应用程序采用“本地优先”的隐私架构，这一点尤为重要。*
- **桌面上下文和屏幕数据：** 为提供能感知上下文的协助，Everywhere 可能通过截图或无障碍 API 处理您屏幕上显示的内容。**此处理在您的设备本地进行。** 除非您明确触发了需要云端处理的功能（例如向某个大型语言模型发送特定截图），否则我们不会将原始屏幕录像或完整截图上传到我们的服务器。
- **聊天记录及设置：** 默认存储在您的设备上。如果您启用云同步，我们会在服务器上存储加密数据以实现同步。
- **遥测及诊断：** 我们使用 **Sentry** 监测性能和稳定性。为保护您的隐私，我们采取以下措施：
    - **清除个人身份信息（PII）：** 桌面端不在 Sentry 用户字段中发送邮箱、用户名或 IP 地址；Passport 会过滤错误报告和日志中的敏感数据。
    - **假名标识符：** 桌面端使用随机生成并保存在本机的标识符，Passport 使用账户 ID 的单向哈希值。
    - **诊断设置：** 桌面端的“仅必要数据”设置仍可能发送错误、指标和较高级别的日志。Passport 的可选会话回放遵循下文的[同意设置](#5-do-we-use-cookies-and-other-tracking-technologies)。
- **推送通知：** 我们可能请求向您发送与账户或功能有关的通知。您可以在设备设置中选择退出。

**服务使用及设备数据**
- **日志和使用数据：** IP 地址、浏览器或设备特征、操作系统、语言偏好以及使用时间戳。
- **设备数据：** 设备 ID、硬件型号及系统配置。
- **位置数据：** 根据 IP 地址推测的大致位置（国家或城市）。我们不收集精确的 GPS 数据。

**数据控制者：** 就欧盟《通用数据保护条例》（GDPR）和英国 GDPR 而言，Sylinko Inc. 是您个人信息的数据控制者。

## 3. 我们依据哪些法律基础处理您的个人信息？ [#3-what-legal-bases-do-we-rely-on-to-process-your-personal-information]

我们仅在具有有效法律依据时处理您的个人信息。根据您所在的位置和与服务的互动方式，我们依赖以下法律依据：

- **同意：** 您已准许我们为特定目的使用您的信息。您可随时撤回同意。
- **履行合同：** 为履行我们对您承担的合同义务（例如提供您请求的服务）。
- **合法利益：** 为我们的合法商业利益，例如改进服务、维护安全和防止欺诈，但这些利益不得优先于您的基本权利和自由。
- **法定义务：** 为遵守适用的法律、法规或法律要求（例如税法或执法机关的要求）。
- **重大切身利益：** 为保护您或其他人的重大切身利益（例如在紧急情况下）。

*有关您所在地区的具体权利（如欧盟及英国的 GDPR、加拿大的 PIPEDA），请参阅下文的[“您享有哪些隐私权？”](#13-what-are-your-privacy-rights)。*

## 5. 我们是否使用 Cookie 和其他跟踪技术？ [#5-do-we-use-cookies-and-other-tracking-technologies]

我们使用 Cookie 及类似跟踪技术（例如 SDK 和本地存储）来提供、保护和改进服务。我们将这些细节集中在此说明，以便您了解我们如何跟踪数据。

**我们使用的技术类型：**
- **严格必要的技术：** 服务运行所必需，例如 Sylinko Passport 的身份验证令牌。这些技术无法禁用。
- **功能和偏好：** 用于记住您的设置（例如主题偏好、语言）并提供增强功能。
- **统计：** Google Analytics 和遮蔽内容的 Passport 会话回放默认关闭，仅在您通过 Cloudflare Zaraz 明确同意统计后启用。回放会遮蔽文本和输入内容，并屏蔽媒体。

**如何控制 Cookie：**
- **浏览器设置：** 您可以设置浏览器，拒绝全部或部分浏览器 Cookie，或在网站设置或访问 Cookie 时提醒您。
- **请勿跟踪：** 我们的系统目前可能不响应浏览器的“请勿跟踪”（DNT）信号，但我们尊重您在应用设置中明确作出的退出选择。网站和 Passport 也识别全球隐私控制（GPC）信号。若您开启 GPC 且未在本站作过明确选择，非必要追踪将保持关闭，不会弹窗询问。GPC 开启时，Passport 不启动回放。

- **[Cookie 偏好](/zh/policies/cookie)：** 您可以在官网页脚的 **Cookie 偏好设置**或 Passport 页脚的 **Cookie 设置**中更改或撤回同意。撤回后，Passport 停止录制并清除回放会话标记。

## 6. 我们是否提供基于人工智能的产品？ [#6-do-we-offer-artificial-intelligence-based-products]

是的，我们的服务包含 AI 驱动的功能。整合这些技术时，我们优先考虑您的隐私。

**AI 技术的使用**

我们使用第三方 AI 服务提供商（如 Anthropic、DeepSeek，以及设置中列出的其他提供商）为 AI 功能提供支持。我们仅为生成回复而与这些提供商共享您的输入及上下文。

**API 中转服务及数据隐私**

当您使用 API 中转服务时，您的提示词和 AI 回复会经由我们的服务器传输至第三方模型提供商。
- **Sylinko 不用于训练：** 我们不使用您的提示词、屏幕上下文或输出来训练自己的模型。但第三方提供商如何使用您的数据受其自身政策约束，例如 [OpenAI 隐私政策](https://openai.com/privacy)和 [Anthropic 隐私政策](https://www.anthropic.com/privacy)。
- **不永久存储内容：** 我们不永久存储您的提示词或生成的回复内容。
- **仅保留元数据：** 我们只为计费和防止滥用保留元数据，例如令牌（token）用量、时间戳和模型类型。

**跨境数据传输（遵守 GDPR 和《个人信息保护法》）：**

- 如适用法律要求就跨境传输单独取得同意，我们须在传输前取得您的同意。

## 8. 我们如何处理您的社交账户登录？ [#8-how-do-we-handle-your-social-logins]

您可以使用 Google 或 GitHub 等第三方社交媒体账户资料注册和登录服务。如果您选择这样做，我们将从相应的社交媒体提供商处收到您的部分个人资料。收到的信息因提供商而异，通常包括服务商账户标识、姓名、电子邮件地址和头像。

我们仅将收到的信息用于本隐私声明所述目的，或在相关服务上另行向您明确说明的目的。我们无法控制第三方社交媒体提供商将您的个人信息用于其他用途，也不对此负责。我们建议您阅读其隐私声明，了解其如何收集、使用和共享您的个人信息，以及如何在其网站和应用中设置隐私偏好。

## 9. 您的信息是否会跨境传输？ [#9-is-your-information-transferred-internationally]

我们的服务商在美国及[第 4 节](#4-when-and-with-whom-do-we-share-your-personal-information)所列其他地区运营。无论您身在何处，您的信息都可能被传输至美国及其他国家，并在这些国家处理。

适用欧洲数据保护法规时，向欧洲经济区或英国境外传输数据须有适用的充分性决定或其他合法机制。如需采取保障措施，我们要求采用欧盟委员会的标准合同条款（SCC）并配合适用的英国传输条款，或采用其他合法的等效保障措施。

## 10. 我们将您的信息保留多久？ [#10-how-long-do-we-keep-your-information]

我们仅在实现本隐私声明所述目的所必要的期限内保留您的个人信息，除非法律要求或允许更长的保留期限（如税务、会计或其他法律要求）。新版 Passport 的删号流程会立即从在用系统删除身份资料、会话和验证记录，并启动头像及 CloudSync 数据库的删除。留存的计费记录会移除个人识别信息；必要的财务及订阅记录因税务和会计需要保留最长七年。Stripe 可能依其自身法定义务保留历史发票。在新版服务上，活跃账户后续认证时会清理过期的会话及验证记录。

当我们不再有持续且合法的业务需要来处理您的个人信息时，我们会将其删除或匿名化。如果无法这样做（例如个人信息已存入备份档案），我们会安全地存储这些信息，并将其隔离，不再进一步处理，直到可以删除为止。

## 12. 我们是否收集未成年人的信息？ [#12-do-we-collect-information-from-minors]

您须年满 13 周岁；如您所在地区的数字同意最低年龄更高，则以较高年龄为准（例如，部分欧盟国家为 16 周岁）。未满 18 周岁还须取得父母或法定监护人的许可。我们不会在知情的情况下收集低于适用最低年龄的儿童的数据、向其索取数据或开展营销。如果我们得知已收集未达该最低年龄的用户的个人信息，我们将停用其账户，并采取合理措施，及时从记录中删除这些数据。如果您发现我们可能已收集未达该年龄的儿童的数据，请通过 [contact@sylinko.com](mailto:contact@sylinko.com) 联系我们。

## 13. 您享有哪些隐私权？ [#13-what-are-your-privacy-rights]

我们认为，无论居住在哪里，您都应能够掌控自己的信息。我们通常对所有用户采用较高的隐私保护标准。根据您所在的地区（如欧洲经济区、英国、加拿大、美国加利福尼亚州等），您可能根据适用法律享有特定权利。

**您的权利包括：**
- **访问权：** 您可以索取我们所持有的、与您有关的个人信息副本。
- **更正权：** 您可以要求我们更正不准确或不完整的信息。
- **删除权：** 您可以要求我们删除个人信息，但某些法定例外情况除外（如税务记录）。
- **限制处理权：** 您可以要求我们限制使用您数据的方式。
- **数据可携带权：** 您可以要求获得结构化、机器可读格式的数据副本。
- **选择退出的权利：** 您可以选择不接收营销信息，并在适用情况下选择退出为定向广告而进行的个人数据出售或共享。
- **撤回同意的权利：** 如我们依据您的同意处理数据，您可以随时撤回同意。

**如何行使权利**

如需行使上述权利，请通过 [contact@sylinko.com](mailto:contact@sylinko.com) 联系我们。我们将依照适用的数据保护法律审议并处理每一项请求。

**特定地区的补充信息：**
- **欧洲经济区、英国、瑞士：** 您有权向当地数据保护机构投诉。
- **美国各州（如加利福尼亚州）：** 我们不出售您的个人信息，也不为跨上下文行为广告共享您的个人信息。我们在适用情况下尊重全球隐私控制（GPC）信号。
